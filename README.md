## How This Portfolio Was Built

This portfolio uses a template from BYU Idaho. It is configured with Quarto and hosted automatically by GitHub. To use this template yourself, follow these steps.

1. Click the green "Use this Template" button and select "Create a new Repo".

2. Choose a name for your repository.

3. Important: check "Include all branches" when creating the repository. This is because we need the hosting branch to publish the website.

4. Once your repo is created, update the links to your GitHub repo in _quarto.yml. Replace every instance of "your_name".

5. The first time you publish to your repo, use this command in the VS Code terminal: `quarto publish gh-pages`.
